# MSE remux bundle

`mseRemux.bundle.js` includes Mediabunny version 1.29.1, copyright Vanilagy and contributors, under the Mozilla Public License 2.0; see `mseRemux.LICENSE.txt`. Its corresponding source is included in the project's pinned `mediabunny` dependency and is also available in the [Mediabunny 1.29.1 npm package](https://www.npmjs.com/package/mediabunny/v/1.29.1).

After installing the project dependencies, regenerate the bundled extension script from `mseRemuxEntry.mjs` and `mseRemux.mjs` with:

```sh
npm run build:remux
```
