# Forge Anywhere · v1.0.26

这个 Chrome / Chromium Manifest V3 扩展将用户选中的网页图片、视频或音频交给已打开的 Inkloom 工作流画布，复用画布已有的拖放上传流程。插件需要本地加载，尚未上架。素材需要能由浏览器获取到可上传的文件；受保护或限制访问的来源可能失败。

## 安装和使用

1. 在 [GitHub 下载最新版](https://github.com/shipenghe/inkloom-forge-anywhere/releases/latest)，从 Assets 下载 `Forge-Anywhere-v1.0.26.zip` 并解压。
2. 打开浏览器的扩展管理页（Chrome 输入 `chrome://extensions`，Edge 输入 `edge://extensions`），开启开发者模式，选择“加载已解压的扩展程序”，选中包含 `manifest.json` 的 `Forge-Anywhere` 文件夹。
3. 登录并打开 Inkloom 工作流画布 `/detail/<画布 ID>`，在插件里将当前画布设为接收目标。一次只保留一个目标；画布必须保持打开。
4. 切换到素材网页，在图片或视频上右键选择“发送到画布”，也可点击素材右上角出现的 Forge 图标。图标只在右键后出现，平时不显示；网站自定义菜单仍会保留。网页的链接覆盖图片时，插件会尝试识别该链接对应的唯一媒体；无法确定媒体时请改用面板选取。
5. 如果首次访问素材来源需要授权，按页面提示打开插件，在面板中授权并发送；有些情况下浏览器会直接请求授权。素材可能来自独立 CDN，权限提示中的域名因此可能与网页不同。拒绝授权将无法通过此方式获取该来源。
6. 若网页首次使用时没有图标，先在该页打开一次插件，启用当前页面的入口；已授予网站访问权限的页面会自动启用。也可在面板选取素材后发送。切换目标时打开新画布并重新设置；目标画布关闭、刷新或切换后也需要重新设置。重新加载插件后，请检查并按需重新设置接收目标和选择素材。

打开插件面板或设置页时，插件会检查 GitHub 上最新发布的版本。发现新版后，面板右上角的齿轮显示红点，设置页版本号旁显示红色「Update」。点击角标会打开对应的 GitHub 发布页，同时下载 ZIP。解压后用新文件替换原扩展目录中的文件，再在浏览器扩展管理页点击“重新加载”。已是最新版时，设置页显示绿底白字的「Latest」。

更新后重新设置接收画布时，插件会核对并更新画布中的连接脚本，旧连接不能继续响应新版本的导入。已有节点的位置不会随插件升级自动重排；需要重新起排时，先平移到空白区域，再导入第一张素材。

面板顶部的 Forge 图标可打开 [Forge 首页](https://forge.art/)。未设置接收画布时，媒体右键菜单显示“打开 Forge”，右键后出现的媒体图标也会打开首页；设置接收画布后恢复发送，不会自动重发之前的素材。

导入文件命名为 `FA Image <毫秒时间戳>` 、`FA Video <毫秒时间戳>` 或 `FA Audio <毫秒时间戳>`，不带扩展名，画布节点沿用这个名称。

图片和视频按原比例显示在面板中。视频或音频交付后，可以点预览区域的播放按钮在面板内播放最近一次交付的文件。播放文件缓存在本机，并在下一次素材交付或浏览器重启时清理。

扩展在浏览器允许访问的网页中准备右键入口。安装时统一声明 HTTP(S) 网页访问权限，用于在播放器加载前准备视频；用户可在浏览器设置中限制网站访问。只有点击发送才向画布交付文件。自动准备视频单独控制，关闭它不会移除图片和视频的右键入口。浏览器限制了来源网站访问时，插件会按需请求恢复所需的访问权限。选中的媒体地址和目标画布信息暂存于浏览器会话中，导入成功后清除选中媒体。插件不要求单独登录，上传身份由目标画布页面提供。

插件通过目标标签页中注入的内容脚本，向画布的拖放入口交付文件，不需要画布单独实现插件接收接口。插件提示“已交给画布”只表示触发了交付；上传、建节点和保存的结果请在画布确认。

视频列表中未播放的封面按图片处理。先开始视频预览，再右键视频卡片；能确认视频帧位于封面上方时，Forge 图标会发送视频文件。列表预览可能比详情页的视频清晰度低；需要较高画质、无法预览或无法确定素材时，请打开视频播放页并选中播放器。即使画布开始处理，文件也可能因现有格式限制、上传或保存失败而无法生成节点，请查看画布提示和结果。

图片优先直接导出网页已展示的画面并编码为 PNG，不额外请求图片地址；其原始格式和元数据不会保留。网页显示的是缩略图或动画时，导出的是当前画面。若网页的跨域限制不允许导出，插件会按需请求来源权限，再尝试获取原文件。获得文件后交给画布上传，不是把源网页链接保存为画布素材。

音频支持 MP3、WAV、M4A、AAC、OGG 和 FLAC。插件先读页面内的 Blob 或浏览器允许读取的同源完整缓存，再按需获取原文件。分段音频流暂未接入。

QQ 音乐请进入网页播放器，让歌曲开始播放，再右键底部的歌曲信息或进度条。也可以在插件面板选择「选取素材」，再点击播放栏。网页分段加载 MP3 时，Forge 会等当前文件的分段收齐再提供入口。试听页可导入已加载的完整试听片段。

交付前插件会按文件内容检查画布支持的图片格式。可直接读取的图片会先转为 PNG；回退获取原文件时，如为 AVIF 等不支持的格式则提示用户。Chrome 的原生右键菜单不能可靠地在点击前获取文件内容，因此菜单不会按真实文件格式提前置灰。

面板在同一素材卡片中保留最近一次素材，展示已选中、正在发送、发送完成或失败，可发送当前选中素材或重新选取。视频时间标注为“全片”或“片段”；片段显示在原视频时间轴中的起止时间，例如“片段 00:20–00:30”；未知时间不会猜测。预览仅从源页面已加载的图片或视频当前帧生成，不额外请求媒体地址；跨域限制不允许读取画面时，显示媒体类型和可读取的页面标题。发送后的反馈和预览保留在这张卡片中，不另设历史模块。“发送完成”表示文件已交给画布，后续上传和保存仍由画布处理。点击接收画布旁的“查看”可以回到对应标签页。

## 导入排列

连续导入的图片和视频按每行 10 个排列，第 11 个从下一行起排。第一张放在首次导入时的视口中央；同一行顶部对齐，下一张接在上一张的显示宽度之后，再留 80 个画布单位的间距。新行回到起始横坐标，放在上一行最高节点（含标题）下方，再留 80 的间距。占地按画布当前的等面积、最长边上限规则计算，无法读取素材尺寸时预留最大占地。缩放、平移画布不会改变后续素材在这组排列中的位置；重新设置接收画布会重新起排。

排列按导入顺序分行，不自动寻找空位或避让已有节点，超出当前视口时继续排列，可缩小或平移画布查看。仅传输失败、尚未触发交付的素材不占位置；已交付但结果不确定的素材仍保留位置，避免延迟上传后与下一张重叠。

## 语言设置

点击面板右上角的设置图标，或在浏览器工具栏右键插件图标并选择“选项”，打开设置页。可选“跟随浏览器”“简体中文”和“English”，选择后自动保存。默认跟随浏览器：简中、繁中等中文环境统一显示简体中文，其他语言显示英文。切换语言会更新面板、右键菜单及网页入口提示，不会重新发送素材或中断当前采集。

语言选择保存在当前浏览器的插件本地存储中；浏览器自己的权限提示和扩展管理界面仍跟随浏览器语言。英文安装说明见 [README.en.md](README.en.md)。

## 自动准备视频

“自动准备视频”默认开启，安装时声明普通网页的访问权限，可在“素材传送”标题右侧关闭；用户主动关闭后会记住选择。授权前已打开的网页需要刷新一次；此后打开的新网页会自动在本地准备可识别的视频片段，无需每次手动开启。右键视频选择“发送到画布”，插件先尝试完整视频，无法获取时再尝试发送已准备的片段。片段可能不完整或无声，发送前不会上传。

设置接收画布后，在素材网页右键可识别的图片或视频，再点击右上角的 Forge 图标即可发送；网页自定义菜单阻止原生右键菜单时也可使用。点击其他位置或按 Esc 可收起。部分跨域嵌入播放器、过小的图片或无法唯一确定的媒体不显示图标。

支持识别 Pexels 等网站素材上方的半透明渐变覆盖层，右键后仍保留网站自定义菜单，并显示 Forge 图标。已加载的视频预览与封面同框时，只有命中层级能确认视频位于封面上方才按视频处理；不透明遮挡或无法区分的多个媒体仍不会猜测选中素材。

同一时间最多准备四个含播放器的网页，每页采集上限为 64 MiB；超过上限时关闭其他视频页并刷新当前页。关闭网页或关闭自动准备后会清理片段；关闭功能不会自动撤销此前已授予的网页权限，可在浏览器的扩展管理中撤销。自动准备不保证支持所有播放器或受保护视频。

## 已知限制

- 画布现有图片上传仅接受静态 JPEG、PNG 和 WebP；AVIF 等其他图片格式会被画布拒绝。插件提示已交给画布不代表格式校验或上传成功。
- 仅识别页面中的 `img`、`video` 和 `audio` 元素，不支持框选、网页背景图、跨域 iframe 内元素或 `canvas` 绘制内容。
- `blob:` 素材会尝试在原页面读取；视频读取失败时，会尝试该视频元素声明的直接视频备用地址，若备用地址尚未授权，可在插件中选取视频，导入失败后点击“授权并重试”。支持情况取决于网页实际提供的资源。
- 分段采集目前支持主线程 MediaSource 的非加密 fMP4 和单组音视频轨道，支持采集期间稳定的时间偏移；播放窗口裁剪时从可用关键帧起保留连续片段，并保持音视频相对时间；不支持 Worker 中的 MediaSource、WebM 分段、加密媒体、采集期间变动的时间设置或切换编码；缺初始化段、关键帧、连续片段或音视频无法对齐时会报错。B 站等网站的具体播放器、清晰度及防护策略可能变化，不能保证全部视频可用。
- 插件会以不超过 192 KiB 的二进制片段传递文件；分段采集与组装上限为 64 MiB，前端接收端上限为 200 MiB，其他上传约束仍由现有画布流程决定。不会绕过现有账号或上传限制。
- 当前版本使用显式目标画布与源页面临时连接。关闭、刷新或页面导航会断开连接；若导入时关闭插件弹窗或页面、浏览器终止后台任务，导入可能中断。重试前请先检查画布，避免重复添加。
- 选中媒体实际经哪个 CDN 分发、是否允许重新请求，取决于来源网站；即使页面可显示也不能保证可以获取原文件。

更新版本时默认每轮递增补丁版本号，并同步面板、manifest 和安装包文件名。

## 遇到问题时

- **找不到接收画布**：打开工作流画布并重新设置，确认目标标签页未关闭或刷新，画布未被弹窗遮挡。
- **右键没有入口或提示无法确定素材**：尝试插件面板的网页选取；网页背景图等不受支持的形式无法选取。
- **无法获取视频**：确认自动准备已开启并刷新网页，再播放后重试；不是所有播放格式都能采集。
- **上传或保存结果不明确**：先检查目标画布是否已有新节点，再决定是否重试，避免重复导入。

扩展回归可运行 `npm test`；这些测试不能替代真实网页、画布和浏览器权限流程的验收。

文案位于 `_locales/en/messages.json` 和 `_locales/zh_CN/messages.json`；修改后运行 `npm run build:i18n`，生成同步加载的 `i18n-data.js` 和用于浏览器元数据的繁中别名。业务错误消息保持原值，仅在展示时翻译，避免影响权限和视频备用策略判断。


## 独立开发与打包

本目录是独立 Git 仓库，根目录包含 `manifest.json`。需要 Node.js 20 或更新版本；不依赖 Inkloom 主项目、内部 npm 源或其视频素材。

```sh
npm ci
npm test
npm run build
npm run package
```

`npm run build` 生成本地语言资源和视频组装 bundle；`npm run package` 会先构建，再生成 `dist/Forge-Anywhere-v1.0.26.zip`。ZIP 内为 `Forge-Anywhere/` 文件夹，只包含运行所需文件及使用说明、第三方许可证，不包含测试、依赖目录或 Git 历史。`package.json` 的 `private` 仅用于避免意外发布到 npm，与 GitHub 仓库可见性无关。

本仓库是 Forge Anywhere 的唯一维护位置，Inkloom 中不再保留插件副本、兼容链接或配套接收代码。开发或本地安装时，在 Chrome 中加载本仓库根目录。由旧目录改为从新目录加载时，浏览器可能分配新的扩展 ID，需要重新设置语言、网站权限和接收画布。

视频回归使用 `fixtures/remux-sample.mp4`，由测试画面和正弦波生成；普通测试无需 FFmpeg。可选再生成方式见 [fixtures/README.md](fixtures/README.md)。
